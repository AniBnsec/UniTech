# AegisTrust Browser Extension (Manifest v3)

This browser extension provides **pre-navigation phishing protection** and **instant TLS certificate trust checking** directly from your browser.

## How to Install (Chrome / Brave / Edge)
1. Open your browser and navigate to `chrome://extensions/` (or `edge://extensions/` / `brave://extensions/`).
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked**.
4. Select this directory: `c:\Users\arind\Downloads\UniTech\extension`.
5. The **AegisTrust Guard** shield icon will appear in your browser toolbar!

## Features
- **One-Click Pre-Navigation Audit:** Click the icon on any tab or paste a link to get an instant risk assessment before visiting.
- **Context Menu Integration:** Right-click any link on the web and select *"Inspect link with AegisTrust"* to trigger a safe, SSRF-guarded backend forensic analysis.
- **On-Chain Proof Verification:** Instantly inspect the cryptographic commitment (`Keccak-256`) registered to the blockchain.
